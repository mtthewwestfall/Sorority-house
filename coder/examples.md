# Example Tasks

Here are 5 example one-line tasks you might give the coder for this repository:

1. "Change the chat history API to return the last 15 messages instead of 8 when reopening a chat."
2. "Add a new `last_login_at` column to the `users` table in `main.py` and update it whenever a user successfully authenticates."
3. "Update the offline Service Worker in `web/sw.js` to cache a new image and bump the `SHELL` cache version."
4. "Add an `/admin/users` route that lists all registered emails and their current subscription tier, protected by `ADMIN_SECRET`."
5. "Modify the trust engine in `main.py` so the final milestone requires 5 distinct days talked instead of 3."
